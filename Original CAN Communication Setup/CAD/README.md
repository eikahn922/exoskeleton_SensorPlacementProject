## Working with the files

1. Enter a design folder and open its **OPEN THIS FIRST** directory.
2. Open the only top-level assembly beginning with **OPEN -**.
3. If SolidWorks requests a missing reference, select the matching original filename from that design's **Assembly Components** directory.

Only top-level assemblies were renamed for recruiter clarity. Supporting parts and the nested Adafruit IMU assembly in Design 1 retain their original filenames. ZIP archives are omitted because the extracted CAD is already organized here.

Treat Designs 1–4 and the lid test as design history. **Final** is the completed, fully validated baseline.
