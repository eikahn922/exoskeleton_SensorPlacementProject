## Opening the CAD

Open **OPEN - Strap-Adjustable Thigh IMU Cuff.SLDASM** inside the **OPEN THIS FIRST** folder. The five supporting parts retain their original SolidWorks filenames in **Assembly Components**.

Only the top-level assembly was renamed for clarity. SolidWorks may request a one-time reference relink after the GitHub-oriented reorganization; select only the matching files from this design's own **Assembly Components** folder.
