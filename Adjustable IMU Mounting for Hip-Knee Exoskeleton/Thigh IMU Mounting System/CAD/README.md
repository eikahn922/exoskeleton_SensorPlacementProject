## Opening Version 2

Open **OPEN - Thigh IMU Cuff - Version 2.SLDASM** inside the Version 2 **OPEN THIS FIRST** folder. Its six supporting parts are collected in **Assembly Components**:

- four unchanged dependencies copied from Version 1;
- the updated `CuffWithIMUStrapAttachment#1.SLDPRT`;
- the new `strapPushdown_thighIMU.SLDPRT` strap-retention component.

Only the top-level assembly was renamed for recruiter navigation. Supporting filenames remain unchanged so SolidWorks can resolve its references. If SolidWorks requests a one-time relink after the GitHub-oriented reorganization, select only the matching files from that revision's own **Assembly Components** folder.
