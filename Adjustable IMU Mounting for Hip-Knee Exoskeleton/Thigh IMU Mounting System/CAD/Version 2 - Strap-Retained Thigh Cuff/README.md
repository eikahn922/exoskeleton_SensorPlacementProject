# Version 2 – Strap-Retained Thigh Cuff

Version 2 is the latest thigh IMU CAD revision. It updates the cuff and adds a dedicated strap-retention/pushdown component while preserving the adjustable placement concept from Version 1.

Open [OPEN THIS FIRST – Thigh IMU Cuff, Version 2](OPEN%20THIS%20FIRST%20-%20Thigh%20IMU%20Cuff%20-%20Version%202), then launch **OPEN - Thigh IMU Cuff - Version 2.SLDASM**.

The package is self-contained: four unchanged dependencies are copied from Version 1, and the updated cuff plus new strap-retention part are included alongside them.

Status: latest CAD revision in an in-progress subsystem; validation remains planned.
