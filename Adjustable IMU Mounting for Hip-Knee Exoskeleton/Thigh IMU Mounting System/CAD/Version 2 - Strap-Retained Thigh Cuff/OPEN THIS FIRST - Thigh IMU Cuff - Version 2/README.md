# Open the Version 2 assembly here

Launch **OPEN - Thigh IMU Cuff - Version 2.SLDASM** in SolidWorks.

All six referenced parts are in **Assembly Components**. The updated cuff and new strap-retention component are combined with the four unchanged Version 1 dependencies so this revision can be opened as a self-contained package.

If SolidWorks asks to locate a component, point it to this folder's **Assembly Components** directory and choose the exact matching filename.
