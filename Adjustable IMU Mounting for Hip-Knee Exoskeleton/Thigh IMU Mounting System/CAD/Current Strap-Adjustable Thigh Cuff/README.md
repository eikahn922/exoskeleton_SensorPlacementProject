# Current Strap-Adjustable Thigh Cuff

This assembly shows the current thigh IMU attachment concept. The strap-routing component moves within the thigh-cuff opening to provide up/down and side-to-side adjustment. The strap passes through that component and wraps around the thigh/cuff, while bolts entering from the opposite side bound vertical travel.
