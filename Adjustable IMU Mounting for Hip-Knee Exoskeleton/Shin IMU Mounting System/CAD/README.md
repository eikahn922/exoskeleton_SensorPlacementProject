# Shin IMU CAD Guide

The source Drive folder is organized into three recruiter-facing views. Stored ZIP archives are extracted except where the full-exoskeleton supporting files are deliberately kept in one component ZIP, as requested.

| Folder | Original Drive source | Role | Entry point |
| --- | --- | --- | --- |
| **Zoomed-In Shin IMU Assembly** | `shinIMUSetup_ZoomedIn_visualization_ASM.zip` | Close mechanical view of the shin, cuff, foam, IMU package, and latest shank bar | [OPEN THIS FIRST](Zoomed-In%20Shin%20IMU%20Assembly/OPEN%20THIS%20FIRST%20-%20Zoomed-In%20Shin%20IMU%20Assembly) |
| **Full Knee Exoskeleton Assembly** | `KneeExo_V1_Assembly_strap_attachment_visualization.zip` | Shin mounting concept in full knee-exoskeleton context | [OPEN THIS FIRST](Full%20Knee%20Exoskeleton%20Assembly/OPEN%20THIS%20FIRST%20-%20Full%20Knee%20Exoskeleton%20Assembly) |
| **Component Iterations** | Drive folders `thigh cuff` and `shank bar` | Two shin-cuff assemblies and four shank-bar part revisions | [Browse iterations](Component%20Iterations) |

The Drive folder named `thigh cuff` contains files named for the shin IMU and maps here to **Shin Cuff**, matching the supplied design content and project scope.

## Opening the CAD

- Open the only top-level assembly beginning with **OPEN -** in each assembly entry folder.
- The zoomed-in and cuff-iteration folders keep loose supporting files in **Assembly Components**.
- The full knee-exoskeleton folder keeps its main assembly visible and all other source files in **Assembly Components.zip**.
- Supporting part filenames and nested-assembly filenames remain unchanged.
- SolidWorks may request a one-time reference relink after reorganization. Use only the dependencies packaged with that same view or iteration.

For the full knee-exoskeleton source, the visible assembly is byte-identical to the supplied top-level assembly after renaming, and the component ZIP contains all 25 remaining source files with no omissions.
