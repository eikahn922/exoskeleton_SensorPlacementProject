# Full Knee Exoskeleton Assembly

This system-level view shows how the shin cuff, strap attachment, shank-bar geometry, and IMU package integrate with the complete knee exoskeleton.

Open [OPEN THIS FIRST – Full Knee Exoskeleton Assembly](OPEN%20THIS%20FIRST%20-%20Full%20Knee%20Exoskeleton%20Assembly), then launch the only assembly beginning with **OPEN -**.

The original archive contains 26 SolidWorks files. The one 43.2 MB top-level knee-exoskeleton assembly remains visible; the other 25 files are packaged in **Assembly Components.zip** to keep this large system view easy to scan. That component archive includes the smaller `shinIMUwithFoam#2.SLDASM` subassembly.

Extract **Assembly Components.zip** beside the visible assembly before opening it in SolidWorks, then relink only to those extracted matching filenames if prompted.
