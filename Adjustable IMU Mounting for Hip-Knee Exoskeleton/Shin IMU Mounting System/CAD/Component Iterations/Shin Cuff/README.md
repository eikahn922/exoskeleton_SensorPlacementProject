# Shin Cuff Iterations

The supplied Drive folder is named `thigh cuff`, but its archives and assemblies are explicitly shin-IMU designs. They are presented here as **Shin Cuff** iterations for clarity.

- [Iteration 1](Iteration%201) — first supplied foam-backed cuff assembly.
- [Iteration 2](Iteration%202) — later supplied foam-backed cuff assembly used as the nested cuff assembly in the zoomed-in view.

Each iteration exposes one clearly labeled top-level SolidWorks assembly and keeps its parts in **Assembly Components**.
