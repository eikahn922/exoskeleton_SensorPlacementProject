## File organization

Each stage contains one **OPEN THIS FIRST** folder. Open the only assembly beginning with **OPEN -**. All supporting parts and any smaller nested assembly are in **Assembly Components**.

Only the six top-level assemblies were renamed for clarity. Part filenames are unchanged. In Iterations 1–3 and the Final Version, the smaller QT Py package assembly remains named **qtpi#1.SLDASM** inside Assembly Components.

SolidWorks may request a one-time relink after this GitHub-oriented reorganization. Relink only to matching filenames inside the same stage's Assembly Components folder; do not substitute dependencies from another iteration.
