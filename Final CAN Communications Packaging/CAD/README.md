## Working with the files

1. Choose a stage and enter its **OPEN THIS FIRST** directory.
2. Open the only top-level assembly beginning with **OPEN -**.
3. If SolidWorks requests a missing reference, select the matching original filename from that stage's **Assembly Components** directory.

Only the two top-level assemblies were renamed. All supporting SolidWorks part filenames remain unchanged. The original ZIP archives are omitted because the integrity-checked CAD has already been extracted into these self-contained stages.
